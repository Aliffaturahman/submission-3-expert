# Cuisine Chaser

Cuisine Chaser is a web-based platform designed to help users discover various culinary destinations across Indonesia. The website provides information about different restaurants and culinary spots, allowing users to explore Indonesian cuisine through an interactive and user-friendly interface.

This project was developed as part of **Submission 3 – Expert Program** at **Dicoding Indonesia**, with a focus on implementing Progressive Web App (PWA), testing, performance optimization, and modern web development practices.

## Features

- Search and explore culinary destinations across Indonesia
- View detailed information about restaurants
- Add and manage favorite restaurants
- Offline access through Progressive Web App (PWA) features
- Responsive design for various screen sizes
- Lazy loading and image optimization for better performance
- Automated unit and end-to-end testing
- Accessible and user-friendly interface

## Technologies

### Frontend

- **HTML**  
  Used to structure the content and elements of the website.

- **CSS**  
  Used to style the website and create a responsive layout.

- **JavaScript (ES6+)**  
  Used to implement website functionality and user interactions.

### Build Tools

- **Webpack**  
  Used to bundle, process, and optimize project assets.

- **Babel**  
  Used to transform modern JavaScript code for browser compatibility.

### Data & Storage

- **REST API**  
  Used to retrieve restaurant data from the server.

- **IndexedDB**  
  Used to store favorite restaurant data locally in the browser.

- **Firebase**  
  Used to deploy and host the Cuisine Chaser web application.

### Progressive Web App

- **Workbox**  
  Used to implement PWA features such as caching and offline access.

### Testing

- **Jest**  
  Used for automated JavaScript unit testing.

### Code Quality

- **ESLint**  
  Used to maintain code quality, consistency, and coding standards.

## Project Purpose

Cuisine Chaser was developed to fulfill the requirements of **Submission 3 – Expert Program** from Dicoding Indonesia. The project applies various concepts learned throughout the program, including Progressive Web App development, application testing, performance optimization, and modern JavaScript development.

The main goal of Cuisine Chaser is to provide users with a convenient platform for discovering culinary destinations while demonstrating the implementation of modern web development practices.
